## تحديث فحص النشر

نجح Mermaid CLI 11.4.2 في تحليل المخططات العشرة الرئيسية وتصديرها، ضمن تثبيت مستقل عن بيئة Python. فُحص مخططان بصرياً فقط؛ صحة جميع الرسوم العلمية واتجاه النص المختلط لم تُراجع بالكامل. نجح Edge headless عند تعطيل GPU وcompositing في إنتاج نسخة PDF إثبات من مسودة HTML السابقة. أظهرت صور الصفحات 1 و138 و274 اتصال الحروف العربية واتجاه الشيفرة وأرقام الصفحات في تلك العينات فقط؛ لا يثبت ذلك سلامة بقية الصفحات أو الفهرس أو المعادلات. نسخة الإثبات لا تحتوي الرسوم المصدرة وهي غير نهائية. لم تُستكمل المراجعة العلمية لكل الأسئلة والفصول أو مراجعة خبير خارجي.
