# لمحة عن النظام

يعيد المشروع بناء إطار بحثي للتنبؤ بالسلاسل المالية وتفسير مخرجاته؛ وهو لا يثبت أنه أعاد إنتاج الجدول الأصلي للرسالة. يوضح README أن البيانات والوحدات والتهيئة الأصلية غير مكتملة وأن ملحق الرسالة يستخدم نماذج مختلفة. لذلك ينبغي وصف المخرجات المحفوظة بأنها نتائج محسوبة حديثاً، لا نتائج أصلية مستعادة.

يستخدم التنفيذ أربع فئات تنبؤ: LinearRegression وRandomForest وGradientBoosting وLSTM، مع مرجع Persistence. يجري بناء السمات والنوافذ وتقسيمها زمنياً ثم اختيار النماذج باستخدام التحقق، وتقييمها على الاختبار. تحفظ الشيفرة التنبؤات والمقاييس والتفسيرات ويعرضها Streamlit. ينص README على أن العرض الافتراضي يعيد عرض نتائج محفوظة وليس تنبؤاً حياً بسوق اليوم.

```mermaid
flowchart LR
    A[لقطات الأسعار المحلية] --> B[السمات والنوافذ الزمنية]
    B --> C[تدريب واختيار بالتحقق]
    C --> D[تنبؤات الاختبار والمقاييس]
    C --> E[تفسيرات SHAP وLIME]
    D --> F[ملفات النتائج المحفوظة]
    E --> F
    F --> G[واجهة Streamlit المحلية]
```

يلخص الشكل المشار إليه المسار العام في `src/xai_finance/pipelines/train.py` وملفات الشرح والواجهة؛ ولا يصف كل فروع التحقق العلمي أو التنزيل.
