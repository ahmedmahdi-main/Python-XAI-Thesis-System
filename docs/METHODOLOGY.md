# Reconstruction methodology

This system implements Chapter 4's narrative under the supplied implementation plan and the user's PyTorch/CUDA override. It is a new, auditable reconstruction, not an exact replication of historical Table 4. Source anchors and appendix contradictions are in THESIS_TRACEABILITY.md.

## Prediction and data

Daily task: after session t closes, predict the next observed session's adjusted close. Actual target date and feature cutoff are saved for every prediction. Exact fixed download range is 2015-01-01 inclusive through 2026-01-01 exclusive. AAPL, ^GSPC, ^IXIC, GC=F and CL=F come from Yahoo via pinned yfinance with auto_adjust=False. Raw CSVs and manifests are immutable, hash-checked on loading, and retain provider, units, adjustment, retrieval time, schema counts, negative closes, missing rows and longest calendar gap. No holiday rows, future interpolations or synthetic empirical data are added.

Features: adjusted OHLC, log1p(unadjusted volume), SMA(5/20), EMA(12/26), Wilder-style EWM RSI(14), MACD(12-26)/signal(9), Bollinger(20, two population standard deviations), daily return, return lags(1/5), trailing return volatility(20), momentum close-minus-close(10), trailing return(20). Indicator initialization uses trailing values; warm-up rows are dropped. Outliers and negative crude-oil futures prices are retained, not winsorized using full history. Returns around nonpositive prices and provider-defined futures rolls require economic caution; no profitability claim is made.

Yahoo's retrospectively adjusted prices can reflect later corporate actions; FRED housing values are revised. These snapshots provide reproducible retrospective regression, not a point-in-time historical investment simulation. Macroeconomic/sentiment data are excluded because release-time/vintage alignment is unavailable.

Monthly housing uses CSUSHPINSA from FRED, observation range 1987-01 through 2025-12, and only actual index values. OHLC and volume are never invented. The monthly experiment forecasts the next index observation retrospectively, uses monthly windows/indicators and is always labeled separately. Unknown release vintages mean it cannot establish publication-time forecasting skill. No monthly errors are pooled with dollar or daily index errors.

## Common information and partitioning

Daily lookback 30, monthly lookback 12. All four models receive the identical full window and identical target dates; sklearn flattens the window and LSTM preserves its time axis. This is a deliberate information-set equality choice, with collinearity and dimensionality limitations for tabular models. Final unlabeled raw row is used only for the explicitly unverified next-snapshot forecast.

Labels are partitioned in strict chronological order: floor(0.8N) train, floor(0.1N) validation, remainder test. Past context is allowed across boundaries; no training label enters validation/test. Test windows may use already observed preceding test closes, because this is rolling one-step forecasting with a frozen model, not a recursive multiday forecast.

No imputation is fitted across all observations. Missing raw observations are dropped, targets are never filled. LinearRegression has a StandardScaler fitted only on training flattened windows. LSTM input and target StandardScalers are fitted on training windows/labels only, frozen thereafter, and predictions inverse-transformed before evaluation. Repeated input observations in overlapping training windows receive their window multiplicity in scaler statistics; this remains training-only.

## Model configuration and selection

Fixed seed 42. LinearRegression uses scaled full-window OLS, not a renamed regularized model. A training-only pivoted QR selector removes numerically dependent columns at relative diagonal threshold 1e-10 before OLS. This corrects a diagnosed condition number around 6.4e19 and coefficients around 8.4e12 in the original unfiltered design, which failed SHAP reconstruction through cancellation. Threshold is a numerical-rank rule, not test-score tuning. Original failed/superseded runs remain recorded; all final models are fitted in a fresh run. Retained columns/rank are exported. Dropped-column SHAP contributions are zero for this chosen representation, which does NOT imply those correlated indicators lack economic information. RandomForestRegressor and sklearn GradientBoostingRegressor preserve the specified families. Full mode compares two declared validation-only settings per tree family, keeping all fitted training cutoffs fixed; no test selection or post-validation refit. Exact candidates, validation errors and runtimes are saved in training.json. Quick mode uses one declared setting per family. Persistence forecasts the current close and is an additional difficulty check.

LSTM: one recurrent layer, 32 hidden units, output dropout .1, linear head, Adam(.001), MSE in standardized target units, gradient norm clipping 1, no shuffling, maximum 60 epochs, patience 8, restore best validation checkpoint. Quick mode maximum 8 epochs. Numerical seeds cover Python/NumPy/torch/CUDA; deterministic algorithms on, cuDNN benchmark and TF32 off; CUBLAS_WORKSPACE_CONFIG=:4096:8 set before CUDA initialization. CLI launch scripts set PYTHONHASHSEED before process startup.

CPU fallback is automatic in auto mode and explicit in metadata. Forced CUDA fails clearly if unavailable. CUDA AMP uses supported BF16 (otherwise FP16/GradScaler); compare finite training-fixture AMP and FP32 loss with a predeclared relative difference limit of 5%, else use FP32. Loss and inverse-scaled evaluation are FP32/FP64. Batch candidates 32/64 are measured using training windows only with a 20% free-VRAM reserve, OOM halving, and largest accepted size selection; timing does not determine the choice. RNG state is restored after probes. Exact selected batch, precision and peak memory are saved. Resume-state checkpoints include optimizer, AMP and RNG states, but the delivered CLI starts new immutable runs rather than silently resuming or overwriting experiments.

## Evaluation and explanations

Final test is evaluated after validation selection. Saved predictions are reused for plotting and independent metric recomputation without retraining. MAE/RMSE/MAPE/R2 use original target units. Zero MAPE targets are excluded with their count; all-zero MAPE and constant-target R2 are explicitly null. Direction accuracy is three-way sign agreement (up/down/unchanged); the supplementary confusion matrix is binary up versus not-up. Precision/recall are null when undefined. No raw MAE is averaged across assets.

Regimes are fixed before evaluation: preceding 20-observation return greater than +5% bull, below -5% bear, otherwise sideways. Monthly means 20 months. Regime definitions use feature-cutoff information only. Counts and errors are reported, with sparse groups treated descriptively. No walk-forward sensitivity or statistical superiority claim is inferred from the core held-out split.

Tree SHAP uses interventional TreeExplainer with training-only background; OLS uses LinearExplainer on its fitted standardized feature space while labels display original values. LSTM uses a flattened-window PermutationExplainer adapter returning original target units. Background indices, seeds, evaluation budget and fixed uniformly spaced test indices are saved. Full mode explains 10 observations/model/asset; quick 3 tabular and 1 LSTM. A single permutation cycle is a bounded approximation, not a converged attribution estimate. Sum-over-lags absolute rankings differ from signed feature contributions and are labeled accordingly.

LIME uses training-only flattened windows, regression mode, seeded sampling and a correct batch predict function. It runs for each declared SHAP test date, with a second seed at the first date. Fidelity is measured as absolute local surrogate error and weighted neighborhood R2; no unsupported quality threshold is claimed. SHAP base plus contributions is checked against the original model (rtol 1e-4/atol 1e-3). Rerun seed stability reports absolute-attribution rank correlation and top-10 overlap. Explanations must leave original predictions unchanged. These checks do not establish causality, realistic interventions, fairness or human trust. Feature correlations and off-manifold masked/sampled combinations are explicitly acknowledged.

No survey is recreated. No numerical result is tuned, rounded into agreement or manually adjusted to historical Table 4.
