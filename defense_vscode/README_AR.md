# عروض النماذج في VS Code

هذه الإضافة تعمل داخل مجلد المشروع أو مجلد الحزمة الأصلية `Mohammad_XAI_Defense_CPU` بعد فك ضغطه؛ ليست حزمة مستقلة. انسخ المجلد `defense_vscode` بجانب `src` و`configs` و`data` و`artifacts` و`pyproject.toml`. يلزم وجود التجربة `artifacts/runs/full_20261021T040901084647Z` بما فيها `inventory.json` ومجلد `AAPL`، ولقطة `data/raw/AAPL.csv` و`data/manifests/AAPL.json`. لا تنقل ملفات النماذج وحدها. حزمة CPU الأصلية تشمل هذه المواد وملفات التثبيت غير المتصل؛ لا يتضمن ZIP الإضافة بيئة Python أو هذه الحزمة الكبيرة. لا تستخدم ملفات joblib أو checkpoints من مصادر غير موثوقة.

1. فك ضغط حزمة CPU الأصلية والإضافة، وانسخ الإضافة إلى جذر الحزمة كما سبق. افتح VS Code ثم File → Open Folder واختر جذر الحزمة، وليس مجلد الإضافة وحده.
2. ثبّت Python 3.12 بنسخة Windows x64 مسبقاً، ثم أعد بيئة CPU من حزمة الدفاع باتباع تعليماتها. من طرفية جذر الحزمة شغّل `SETUP_DEMO.bat --offline` لاستخدام الحزم المحلية فقط. في VS Code اختر Python: Select Interpreter من لوحة الأوامر، ثم Python 3.12 من البيئة التي أنشأتها الحزمة. لا تنسخ بيئة افتراضية من جهاز آخر. راجع `requirements-cpu.txt` وملفات wheel المحلية في الحزمة الأصلية عند إصلاح الاعتماديات.
3. افتح أحد الملفات `01_linear_regression.py` إلى `06_compare_all_models.py`. اضغط زر **Run Python File** أعلى المحرر. يمكن أيضاً تشغيل `python defense_vscode/01_linear_regression.py` من جذر المشروع بعد تفعيل البيئة؛ غيّر اسم الملف لكل نموذج.
4. اقرأ اسم التجربة والخصائص والأبعاد والصفوف العشرة الأولى وقيم MAE وRMSE وMAPE وR² في Terminal. ملف CSV يحتوي جميع صفوف الاختبار، والسعر الحقيقي والتنبؤ بوحدة الدولار المعدّل. النتائج المعروضة حسابات جديدة لاستدلال أوزان محفوظة، وليست تدريباً جديداً أو نتائج الأطروحة المنقولة حرفياً.
5. افتح `defense_vscode/outputs/اسم_النموذج/prediction_vs_actual.png` و`predictions.csv` و`metrics.json`. المقارنة في `outputs/comparison/`. اضغط Ctrl+C في الطرفية لإيقاف التشغيل. لإعادته اضغط زر التشغيل مجدداً؛ تُستبدل مخرجات العرض فقط، ولا تُعدل أدلة البحث. يمكن حذف مخرجات العرض بعد الاحتفاظ بما تريد.
6. إذا ظهر خطأ ملف مفقود، تحقق من بنية الحزمة ومسار التجربة أعلاه. إذا ظهر `ModuleNotFoundError` أو خطأ إصدار عند تحميل نموذج، اختر بيئة CPU الخاصة بالحزمة وشغّل إعدادها المحلي حسب تعليماتها. لا ينزّل العرض أي بيانات أو حزم. إذا فشل تحقق البصمة أو مقارنة التنبؤات فلا تعتمد النتائج؛ أعد النسخة السليمة من الحزمة الأصلية. اختلاف جهاز CPU قد يسبب اختلافاً عددياً صغيراً؛ يُتحقق منه وفق سماحية إعادة التحميل الأصلية، وإلا يتوقف العرض برسالة خطأ.

الرسوم تستخدم تسميات إنجليزية لتجنب مشاكل خطوط العربية؛ الشرح في الطرفية والوثائق عربي. في Windows يمكن اختيار UTF-8 للطرفية إن ظهرت الحروف مشوهة. العرض لا يستدعي Streamlit ولا SHAP أو LIME ولا يحتاج GPU. راجع `MODEL_EXPLANATIONS_AR.md` و`DEFENSE_PRESENTATION_AR.md` قبل العرض.
